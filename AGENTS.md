# Project documentation

When changing Atlus data preparation, modeling, evaluation, or research
conclusions, update `docs/PROJECT_LOG.md` in the same task. Record the date,
question, inputs, eligible city count, method, comparison, result, limitations,
and any decision changed. Preserve earlier attempts, including unsuccessful
ones, so the log remains an honest history rather than a summary of winners.

Keep `experiments/README.md` aligned with reproducible commands and the latest
verified experiment outputs. Do not claim an experiment ran unless its saved
report or held-out predictions can be checked.
